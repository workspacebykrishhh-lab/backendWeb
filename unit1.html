1 The Internet

The Internet is a worldwide network of connected computers that share information using common rules called protocols. It is the system that carries websites, email, video calls and online services to billions of people.

Client

Your device and browser that asks for a web page.

Server

A computer that stores the website and sends it back.

ISP

Internet Service Provider, the company that gives you access to the internet.

2 Internet Protocols

A protocol is a set of rules that lets two computers talk to each other. These four are the most important.

ProtocolFull FormWhat it does
TCP/IPTransmission Control Protocol / Internet ProtocolIP delivers data packets to the right address; TCP makes sure all packets arrive correctly and in order.
HTTPHyperText Transfer ProtocolUsed by browsers to request and receive web pages. HTTPS is the secure version.
DNSDomain Name SystemConverts website names into IP addresses.
SMTPSimple Mail Transfer ProtocolSends emails from a client to a mail server and between mail servers.

3 IP Addressing

An IP address is a unique number given to every device on a network, like a house address for your computer.

VersionSizeExample
IPv432 bits (4 numbers, 0–255)192.168.1.10
IPv6128 bits (hexadecimal)2001:0db8:85a3::8a2e:0370:7334
IPv4 addresses are running out, so IPv6 was created to give a far larger number of addresses.

4 Domain Name System (DNS)

People remember names like google.com, while computers use numbers. DNS works like a phone book that finds the IP address for a domain name.

  • You type a website name in the browser.
  • The browser asks a DNS server for the IP address.
  • The DNS server replies with the IP address.
  • The browser connects to that IP and loads the page.

5 Hypertext Markup Language (HTML)

HTML is the standard language used to create the structure of a web page. It uses tags such as headings, paragraphs, links, images, lists and tables.

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is my web page.</p>
    <a href="https://example.com">Visit link</a>
  </body>
</html>
TagPurpose
<h1>–<h6>Headings
<p>Paragraph
<a>Hyperlink
<img>Image
<table>Table
<form>User input form

6 JavaScript Programming Fundamentals

JavaScript makes web pages interactive. It runs in the browser and can change content, respond to clicks and check form input.

let name = "Krish";        // variable
const year = 2025;         // constant

function greet(person) {   // function
  return "Hello, " + person;
}

if (year > 2020) {         // decision
  console.log(greet(name));
}

for (let i = 1; i <= 3; i++) {   // loop
  console.log(i);
}

Variables

var, let and const store data.

Data types

Number, String, Boolean, Array, Object, Null, Undefined.

Control flow

if/else, switch, for, while.

Functions & events

Reusable code blocks that react to user actions.
