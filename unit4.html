1 Connectivity with the Database

MySQL is a popular database that stores data in tables. PHP connects to it using the mysqli extension. You need the server name, username, password and database name.

<?php
$conn = mysqli_connect("localhost", "root", "", "college");

if (!$conn) {
    die("Connection failed: " . mysqli_connect_error());
}
echo "Connected successfully";
?>
With XAMPP, the default server is localhost, user is root and the password is empty.

2 Database Creation and Creating Tables

First a database is created, then tables are added inside it. A table has columns (fields) and rows (records).

CREATE DATABASE college;
USE college;

CREATE TABLE students (
  id     INT AUTO_INCREMENT PRIMARY KEY,
  name   VARCHAR(50) NOT NULL,
  email  VARCHAR(60),
  course VARCHAR(30)
);

The same can be run from PHP:

<?php
mysqli_query($conn, "CREATE DATABASE college");

$sql = "CREATE TABLE students (
          id INT AUTO_INCREMENT PRIMARY KEY,
          name VARCHAR(50) NOT NULL,
          email VARCHAR(60),
          course VARCHAR(30))";

if (mysqli_query($conn, $sql)) {
    echo "Table created";
}
?>

3 Insertion of Data

The INSERT INTO statement adds a new record to a table.

<?php
$sql = "INSERT INTO students (name, email, course)
        VALUES ('Krish', 'krish@mail.com', 'BCA')";

if (mysqli_query($conn, $sql)) {
    echo "Record added";
} else {
    echo "Error: " . mysqli_error($conn);
}
?>

4 Retrieval of Data

The SELECT statement reads records. PHP then loops through the result using mysqli_fetch_assoc(), which gives one row at a time as an array.

<?php
$result = mysqli_query($conn, "SELECT * FROM students");

echo "<table border='1'>";
while ($row = mysqli_fetch_assoc($result)) {
    echo "<tr>
            <td>" . $row['id'] . "</td>
            <td>" . $row['name'] . "</td>
            <td>" . $row['course'] . "</td>
          </tr>";
}
echo "</table>";
?>

5 Data Manipulation

Existing records can be changed with UPDATE or removed with DELETE. Always use a WHERE condition, otherwise every row is affected.

<?php
// UPDATE a record
mysqli_query($conn, "UPDATE students SET course='MCA' WHERE id=2");

// DELETE a record
mysqli_query($conn, "DELETE FROM students WHERE id=3");

// close the connection
mysqli_close($conn);
?>
