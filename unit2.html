1 Basic Syntax

PHP is a server-side scripting language used to build dynamic websites. PHP code is written inside <?php ... ?> tags, every statement ends with a semicolon, and the file is saved with a .php extension.

<?php
  echo "Hello, World!";   // prints text
  // single-line comment
  # another comment
  /* multi-line comment */
?>

2 Variables and Constants

A variable stores data and always starts with a $ sign. A constant holds a value that cannot change once it is set.

<?php
  $name = "Krish";          // variable
  $age  = 20;

  define("COLLEGE", "ABC College");   // constant using define()
  const COURSE = "BCA";               // constant using const

  echo $name . " studies " . COURSE;
?>
Variable names are case-sensitive: $name and $Name are different.

5 Decision Making Statements

These let the program choose what to do based on a condition: if, if...else, elseif and switch.

<?php
  $marks = 72;

  if ($marks >= 75) {
      echo "Distinction";
  } elseif ($marks >= 40) {
      echo "Pass";
  } else {
      echo "Fail";
  }

  switch ($day) {
      case "Sun": echo "Holiday"; break;
      default:    echo "Working day";
  }
?>

6 Looping Constructs

Loops repeat a block of code. PHP has four main loops.

for

Used when you know how many times to repeat.

while

Repeats while a condition is true.

do...while

Runs at least once, then checks the condition.

foreach

Goes through every item of an array.

<?php
  for ($i = 1; $i <= 5; $i++) {
      echo $i . " ";
  }

  $colors = ["Red", "Green", "Blue"];
  foreach ($colors as $c) {
      echo $c . "<br>";
  }
?>

7 Mixing Decisions and Loops with HTML

PHP can be placed inside HTML to build pages dynamically. For example, a loop can create table rows, and an if can show or hide content.

<table border="1">
<?php for ($i = 1; $i <= 5; $i++) { ?>
  <tr>
    <td><?php echo $i; ?></td>
    <td><?php echo ($i % 2 == 0) ? "Even" : "Odd"; ?></td>
  </tr>
<?php } ?>
</table>

8 String Handling

A string is a sequence of characters. It can be written in single or double quotes. Double quotes also read variables inside the text.

Creating and accessing a string

<?php
  $str = "Hello PHP";
  echo $str[0];        // H  (first character)
  echo $str[-1];       // P  (last character)
  echo "Name: $name";  // variable inside double quotes
?>

Searching and replacing

<?php
  echo strpos("Hello World", "World");            // 6
  echo str_replace("World", "PHP", "Hello World"); // Hello PHP
?>

Formatting a string

<?php
  printf("Price: %.2f", 99.5);     // Price: 99.50
  echo number_format(1234567.891, 2); // 1,234,567.89
  echo sprintf("Roll %05d", 42);   // Roll 00042
?>
