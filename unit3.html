1 Creating a Form

A form collects information from the user, such as a name or password. The action attribute says which PHP file will receive the data, and method says how it is sent (GET or POST).

<form action="process.php" method="post">
  <label>Name:</label>
  <input type="text" name="username">
  <input type="submit" value="Send">
</form>
The name attribute of each input becomes the key used in PHP, for example $_POST['username'].

2 Submitting Data to the Server (GET and POST)

When the user presses submit, the browser sends the form data to the server, where PHP reads it using special arrays called superglobals.

GET

Data is added to the URL, like process.php?username=Krish. Read with $_GET.

POST

Data is sent inside the request body, hidden from the URL. Read with $_POST.

<?php
  $a = $_GET['username'];     // data sent by GET
  $b = $_POST['username'];    // data sent by POST

  echo "Hello, " . htmlspecialchars($b);
?>

4 Student Registration Form with Server-side Validation

Server-side validation means PHP checks the data after it reaches the server. This is important because browser checks can be bypassed. Here is how the form looks:

register.php

<?php
$errors = [];

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $name   = trim($_POST['name']);
    $email  = trim($_POST['email']);
    $phone  = trim($_POST['phone']);
    $course = $_POST['course'];
    $pass   = $_POST['password'];

    if (empty($name) || !preg_match("/^[a-zA-Z ]+$/", $name))
        $errors[] = "Name must contain only letters.";

    if (!filter_var($email, FILTER_VALIDATE_EMAIL))
        $errors[] = "Enter a valid email address.";

    if (!preg_match("/^[0-9]{10}$/", $phone))
        $errors[] = "Phone number must be 10 digits.";

    if (strlen($pass) < 6)
        $errors[] = "Password must be at least 6 characters.";

    if (empty($errors)) {
        echo "Registration successful!";
    } else {
        foreach ($errors as $e) {
            echo "<p style='color:red'>$e</p>";
        }
    }
}
?>

Validation rules used

  • empty() checks that a field is not blank.
  • trim() removes extra spaces.
  • filter_var() checks the email format.
  • preg_match() checks text against a pattern.
  • htmlspecialchars() protects the page from harmful input.

5 Login Form with Server-side Validation

The login form asks for a username and password. PHP checks that both are filled and then compares them with the stored values.

login.php

<?php
session_start();
$error = "";

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $user = trim($_POST['username']);
    $pass = trim($_POST['password']);

    if (empty($user) || empty($pass)) {
        $error = "All fields are required.";
    } elseif ($user == "admin" && $pass == "admin123") {
        $_SESSION['user'] = $user;       // remember the user
        header("Location: welcome.php"); // go to next page
        exit();
    } else {
        $error = "Invalid username or password.";
    }
}
?>

<form method="post">
  <input type="text" name="username">
  <input type="password" name="password">
  <input type="submit" value="Login">
  <p style="color:red"><?php echo $error; ?></p>
</form>
In a real project, passwords are stored as hashes using password_hash() and checked with password_verify().
